# نظام تصميم إحكام — Ihkaam Design System

> **الهوية في جملة:** بنتو داكن دافئ (Muted Dark Bento) — أسطح صلبة، حدود فيروزية خافتة، لمسات رملية/وردية ترابية. عربي أولاً، RTL أصلاً.

---

## 1. الألوان — Color Tokens

### الأسطح (Surfaces)

| التوكن | القيمة | الاستخدام |
|---|---|---|
| `canvas` | `#010D0D` | خلفية الصفحة — أسود مائل للفيروزي الدافئ |
| `surface-1` | `#011A1A` | وجه صندوق البنتو (الكرت الأساسي) |
| `surface-2` | `#012424` | لوحات داخلية مرتفعة، أقسام متداخلة |
| `sand` | `#E5D3B3` | سطح فاتح — يُستخدم كـ"شهقة" بين الأقسام الداكنة |

### النصوص (Text)

| التوكن | القيمة | الاستخدام |
|---|---|---|
| `text-1` | `#EAE4DF` | العناوين والنص الأساسي — أبيض مكسور دافئ |
| `text-2` | `#7A9E96` | النص الثانوي، الوصف، الشرح |
| `text-3` | `#5A8A78` | التسميات الخافتة، أرقام الصفحات |
| `text-on-sand` | `#010D0D` / `#012424` | النص فوق السطح الرملي |

### اللمسات (Accents)

| التوكن | القيمة | الاستخدام |
|---|---|---|
| `turquoise` | `#6ABDB2` | اللمسة الأساسية — أزرار CTA، التسميات، الأيقونات |
| `turquoise-hover` | `#7ECDC3` | حالة hover للـ CTA |
| `rose` | `#D9ACA3` | وردي مغبّر — لمسة ثانوية، تنبيه ناعم |
| `clay` | `#A6756A` | طيني — للفقد/الخسارة/الحالة السلبية |

### الحدود (Borders)

```css
--border-default: rgba(2, 115, 104, 0.16);   /* حد البنتو الافتراضي */
--border-hover:   rgba(106, 189, 178, 0.28); /* يتوهج عند hover */
--border-glass:   rgba(106, 189, 178, 0.35); /* لوحات زجاجية */
```

### التدرّج التوقيعي (Signature Gradient)

```css
background: linear-gradient(135deg, #E5D3B3 10%, #D9ACA3 55%, #A6756A 95%);
```
رملي → وردي مغبّر → طيني. يُستخدم **فقط** على كلمة أو كلمتين داخل عنوان (`background-clip: text`) — أبداً كخلفية كاملة.

## 2. الخطوط — Typography

```css
--font-arabic: 'Cairo', sans-serif;        /* weights: 300,400,500,700,800,900 */
--font-mono:   'JetBrains Mono', monospace; /* أرقام، URLs، بيانات تقنية */
```

**القاعدة:** كل نص عربي بـ Cairo. كل رقم إحصائي أو نص لاتيني تقني بـ JetBrains Mono — التباين بينهم جزء من الهوية.

### السلّم (Scale)

| المستوى | الحجم | الوزن | line-height | الاستخدام |
|---|---|---|---|---|
| `display-xl` | 68px | 900 | 1.3 | عنوان الغلاف الرئيسي |
| `display` | 50px | 900 | 1.38 | عناوين الأقسام |
| `h1-light` | 42px | 800 | 1.45 | عنوان على السطح الرملي |
| `card-title` | 25px | 800 | 1.45 | عنوان الكرت |
| `sub` | 22px | 400 | 1.75 | نص شارح (max-width: 760px) |
| `body` | 19px | 400 | 1.7 | نص الكرت |
| `label` | 17px | 700 | 1.6 | تسمية فوق العنوان — بلون اللمسة |

- **letter-spacing** للعناوين الكبيرة: `-0.5px` (العربي يتنفّس أحسن مضغوط شوي)
- **line-height** للنص العربي **لا تنزل تحت 1.7** — الحروف العربية طويلة عمودياً

> في الويب (Tailwind) السلّم أصغر: `text-xs` و `text-sm` هما الأكثر استخداماً للواجهة، والأحجام الكبيرة أعلاه للماركتينغ والهيرو.

## 3. الأشكال — Shape & Radius

| العنصر | Radius |
|---|---|
| صندوق البنتو (الأساسي) | `20px` |
| لوحات وكروت داخلية | `16px` (`2xl`) |
| عناصر صغيرة، أزرار | `12px` (`xl`) |
| Pills، badges، صور شخصية | `9999px` (`full`) |

الأكثر استخداماً فعلياً: `rounded-full` (94×) ← `rounded-xl` (49×) ← `rounded-2xl` (45×).

## 4. المكوّن الأساسي — The Bento Box

> **مهم:** بنتو، **مش** glassmorphism. سطح صلب، بلا `backdrop-filter`، بلا blur.

```css
.bento {
  background:    #011A1A;
  border:        1px solid rgba(2, 115, 104, 0.16);
  border-radius: 20px;
  transition:    border-color 400ms ease-out,
                 box-shadow   400ms ease-out,
                 transform    400ms ease-out;
}
.bento:hover {
  border-color: rgba(106, 189, 178, 0.28);
  box-shadow:   0 0 0 1px rgba(106, 189, 178, 0.06),
                0 24px 64px rgba(0, 0, 0, 0.50);
  transform:    translateY(-3px);
}
```

## 6. الحركة — Motion

| القاعدة | القيمة |
|---|---|
| مدة الانتقال الافتراضية | `400ms ease-out` |
| رفع الكرت عند hover | `translateY(-3px)` |
| رفع الزر عند hover | `translateY(-2px)` |
| الظل عند الرفع | `0 24px 64px rgba(0,0,0,0.50)` |

**الفلسفة:** الحركة بطيئة ومقصودة. لا شي يقفز. الكرات الضوئية (orbs) تنجرف على مدى **14–20 ثانية** بشفافية `0.05–0.18` فقط — حضور بالكاد محسوس، مش عرض.

```css
/* Ripple عند الضغط */
animation: ripple-out 0.65s cubic-bezier(0.22, 1, 0.36, 1) forwards;
```

## 8. RTL — قواعد إلزامية

1. `dir="rtl"` على `<html>`، و `direction: rtl` على `<body>`.
2. استخدم **الخصائص المنطقية**: `margin-inline-start` بدل `margin-left`، و `border-inline-end` بدل `border-right`.
3. **التدرّجات تنعكس:** `to left` في RTL = `to right` في LTR. انتبه لكل gradient.
4. **الزمن يمشي يمين ← يسار.** في أي رسم بياني، البداية على اليمين والنهاية على اليسار — ولازم تسميات المحور تُكتب بنفس الترتيب.
5. **الاستثناء:** شريط المتصفح في موك-أب اللابتوب يبقى `direction: ltr` — لأنه هيك بالواقع.

## 9. مبادئ التصميم — Principles

1. **بنتو، مش زجاج.** أسطح صلبة وحدود واضحة. بلا blur نهائياً.
2. **إيقاع الشهقة.** بعد قسمين داكنين، ضع قسم رملي فاتح `#E5D3B3`. التباين هو الراحة.
3. **اللمسة نادرة.** الفيروزي والوردي والطيني تُستخدم بقلّة — على تسمية أو رقم أو حد. لمّا كل شي ملوّن، ما في شي بارز.
4. **المنتج هو البطل.** في الماركتينغ، أظهر واجهة حقيقية داخل إطار جهاز — لا رسوم توضيحية ولا صور مخزنية.
5. **التداخل يصنع العمق.** كرت الإحصائية العائم يجلس **فوق** الجهاز، مش جنبه.
6. **النص يحمل الحجة.** الهوية عربية بالدرجة الأولى — التايبوغرافي هو التصميم، مش الديكور.

## 10. التركيب البصري — Composition

> الأقسام 1–9 تقول **ماذا لا تفعل**. هذا القسم يقول **كيف تبني**. بدونه يخرج التصميم صحيحاً وميتاً: نص على اليمين، نص تحته، فراغ.

### 10.1 قفزة الحجم (Scale Jump) — القاعدة الأولى

في كل تصميم، **العنصر الأكبر يجب أن يكون 4× الأصغر على الأقل**. إن كانت كل الأحجام متقاربة، فالتصميم مسطّح مهما كانت ألوانه صحيحة.

```
❌ عنوان 50px · نص 22px · تسمية 17px   → مدى ضيّق، لا توتر
✅ عنوان 92px · نص 22px · تسمية 15px   → قفزة 6×، العين تعرف أين تبدأ
```

### 10.2 الطبقات الثلاث — كل تصميم فيه ثلاث طبقات

| الطبقة | z | المحتوى |
|---|---|---|
| **خلفية** | 1 | رقم شبح ضخم، نمط نقاط، توهّج radial، خط SVG |
| **محتوى** | 5 | العنوان والنص — داخل الهامش |
| **عائمة** | 9 | بطاقة/رقم/شارة **تجلس فوق حدّ عنصر آخر أو تقطع الهامش** |

الطبقة الثالثة هي الفرق بين «سلايد» و«بوستر». لو حذفتها، عاد التصميم مسطّحاً.

### 10.3 الرقم الشبح (Ghost Numeral)

```css
.ghost {
  position: absolute; top: -60px; right: -40px;
  font: 900 420px/1 'Cairo', sans-serif;
  color: rgba(106,189,178,0.045);   /* 0.03–0.06 — بالكاد يُرى */
  z-index: 1; pointer-events: none;
  user-select: none;
}
```
يُقصّ على حافة المربع دائماً — الرقم الكامل داخل الإطار يبدو كديكور، والمقصوص يبدو كتكوين.

### 10.4 كسر الهامش (Bleed) — إلزامي

الهامش القياسي `88px`. **عنصر واحد على الأقل في كل تصميم يجب أن يخترقه** — يخرج من الحافة أو يُقصّ بها:

- رقم شبح مقصوص من الأعلى/اليمين
- شريط لمسة يمتد من الحافة إلى الحافة
- بطاقة تخرج 40px خارج حدود العمود
- توهّج radial مركزه خارج المربع

بلا كسر واحد، التصميم يبدو كمستند Word.

### 10.5 قاعدة الفراغ الميت

**ممنوع فراغ عمودي > 120px بين كتلتين.** إن ظهر، الحلّ ليس تكبير الفراغ بل **ملؤه**: مقياس، بطاقة صغيرة، خط فاصل، رقم، أو تكبير العنوان.

### 10.6 القطر (Diagonal Read)

ثقل التكوين على **أعلى اليمين** (البداية في RTL)، والحلّ/الخاتمة على **أسفل اليسار**. الخط الواصل بينهما قطري — لا تصفّ كل شيء عمودياً على اليمين.

### 10.7 التباين النصّي داخل السطر

العنوان الجيد ليس سطراً واحداً بوزن واحد. اكسره:

```html
<div class="display">
  كم طالباً
  <span class="grad">تراجع</span>
  <span style="font-weight:300; color:#7A9E96;">مستواه</span>
  في آخر شهرين؟
</div>
```
وزن 900 + وزن 300 + تدرّج في نفس السطر = التايبوغرافي يصير تصميماً.

**قيد التدرّج:** كلمة أو كلمتان، **على سطر واحد لا يلتف**. ضع `white-space: nowrap` على الـ span — التدرّج المكسور عبر سطرين يبدو كخلل.

### 10.8 المراسي غير النصية

كل تصميم يحتوي **عنصراً واحداً غير نصّي على الأقل**: شريط لمسة 3px، خط SVG، شبكة نقاط، دائرة توهّج، فاصل متدرّج، أو إطار بطاقة. النص وحده — مهما أُحسن ترتيبه — يقرأ كشريحة عرض تقديمي.

### 10.9 إصلاح RTL: الأرقام والمسارات

الـ bidi يقلب `01 / 08` إلى `08 / 01`. اعزل كل تسلسل لاتيني/رقمي:

```html
<div class="pager"><span dir="ltr">01 / 08</span></div>
<span dir="ltr">ihkaam.app</span>
<span dir="ltr">68% / 84%</span>
```

### 10.10 قائمة فحص قبل التسليم

- [ ] أكبر عنصر ≥ 4× أصغر عنصر
- [ ] الطبقات الثلاث موجودة (خلفية / محتوى / عائم)
- [ ] عنصر واحد على الأقل يكسر الهامش
- [ ] لا فراغ عمودي > 120px
- [ ] عنصر واحد غير نصّي على الأقل
- [ ] التدرّج على سطر واحد، كلمة أو كلمتان
- [ ] كل رقم/لاتيني داخل `dir="ltr"`

  /* Borders */
